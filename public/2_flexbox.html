1. Introdução ao Flexbox

Flexbox é um modelo de layout do CSS utilizado para organizar, alinhar e distribuir elementos dentro de um contêiner.

Flex Container

É o elemento pai que recebe a propriedade display: flex. Ele controla como seus elementos filhos serão organizados.

Flex Items

São os elementos filhos diretos do Flex Container, que passam a seguir as regras de organização do Flexbox.

Item 1
Item 2
Item 3
.container {
    display: flex;
}

Main Axis e Cross Axis

O Flexbox trabalha com dois eixos principais:

  • Main Axis: eixo principal, que acompanha a direção definida pelo flex-direction.
  • Cross Axis: eixo transversal, perpendicular ao eixo principal.
Importante: quando utilizamos flex-direction: row, o eixo principal é horizontal. Quando utilizamos column, o eixo principal passa a ser vertical.

2. Display Flex

A propriedade display: flex transforma um elemento em um Flex Container, permitindo controlar a disposição dos seus filhos.

2
3
.container {
    display: flex;
}

3. Flex Direction

Define a direção em que os elementos serão organizados dentro do Flex Container.

Row

Organiza os elementos horizontalmente, da esquerda para a direita.

1
2
3

    display: flex;
    flex-direction: row;
}

Row Reverse

Inverte a ordem visual dos elementos na direção horizontal.

1
2
3

    display: flex;
    flex-direction: row-reverse;
}

Column

Organiza os elementos verticalmente, de cima para baixo.

1
2
3
.container {
    display: flex;
    flex-direction: column;
}

Column Reverse

Inverte a ordem visual dos elementos na direção vertical.

1
2
3

9. Flex Grow, Shrink e Basis

Essas propriedades controlam como os elementos crescem, diminuem e definem seus tamanhos iniciais dentro do Flex Container.

Flex Grow

Define a capacidade de um elemento crescer para ocupar o espaço livre disponível.

Grow 1
Grow 2
Grow 1
.item {
    flex-grow: 1;
}

.item:nth-child(2) {
    flex-grow: 2;
}
O segundo elemento recebe uma proporção maior do espaço livre disponível em relação aos outros dois.

Flex Shrink

Define a capacidade de um elemento diminuir quando o espaço disponível é insuficiente.

Shrink 1
Shrink 0
.item {
    flex-shrink: 1;
}

.item:nth-child(2) {
    flex-shrink: 0;
}
O segundo elemento não diminui de tamanho, enquanto o primeiro absorve a redução necessária.

Flex Basis

Define o tamanho inicial de um Flex Item antes da distribuição do espaço disponível.

200px
200px
.item {
    flex-basis: 200px;
}

Flex (Atalho)

Permite definir grow, shrink e basis em uma única declaração.

Item 1
Item 2
Item 3
.item {
    flex: 1 1 150px;
}

/* grow | shrink | basis */

10. Align Self

Permite modificar individualmente o alinhamento de um Flex Item no eixo transversal, independentemente do alinhamento definido pelo contêiner.

Center
Start
End
Stretch
.container {
    display: flex;
    align-items: center;
}

.item:nth-child(2) {
    align-self: flex-start;
}

.item:nth-child(3) {
    align-self: flex-end;
}

.item:nth-child(4) {
    align-self: stretch;
}

11. Order

Permite modificar a ordem visual dos elementos dentro do Flex Container sem alterar a estrutura original do HTML.

Item 1
Item 2
Item 3
.item:nth-child(1) {
    order: 3;
}

.item:nth-child(2) {
    order: 1;
}

.item:nth-child(3) {
    order: 2;
}
Os elementos são exibidos na ordem definida pela propriedade order. Por padrão, todos possuem o valor 0. Valores menores aparecem antes dos maiores.

Atenção: a propriedade order altera a ordem visual, mas não modifica a ordem original dos elementos no HTML nem necessariamente a ordem de navegação por teclado.

12. Aplicações práticas do Flexbox

O Flexbox pode ser utilizado em diversas situações durante o desenvolvimento de interfaces.

Exemplo: Menu de navegação

Início
Sobre
Contato
.menu {
    display: flex;
    background-color: #ddd;
    padding: 10px;
    margin: 15px 0;
    min-height: 100px;

    justify-content: space-between;

    align-items: center;
}

Esses exemplos demonstram como diferentes propriedades podem ser combinadas para construir componentes e layouts de uma interface.
