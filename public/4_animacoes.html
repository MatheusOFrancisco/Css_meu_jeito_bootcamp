Aprendendo a criar movimentos e interações com CSS.

Introdução Transitions Transform Keyframes Animation Timing Hover Responsividade

1. Introdução às animações CSS

As animações em CSS permitem modificar propriedades visuais dos elementos ao longo do tempo, criando movimentos e efeitos que tornam uma página mais interativa.

Transitions

São utilizadas para criar transições suaves entre dois estados de um elemento, como uma mudança de cor ao passar o mouse.

Animations

Permitem criar animações personalizadas, com diferentes etapas, durações e repetições, utilizando a regra @keyframes.

Diferença: Transitions geralmente dependem de uma mudança de estado, enquanto Animations podem ser executadas automaticamente e possuir várias etapas.

2. Transitions

A propriedade transition controla como uma mudança de propriedade CSS acontece ao longo do tempo.

Transition Property

Define qual propriedade receberá a transição. Neste exemplo, a cor de fundo muda suavemente.

Passe o mouse
.item {
    transition-property: background-color;
    transition-duration: 0.5s;
}

.item:hover {
    background-color: orange;
}

Transition Duration

Determina quanto tempo a transição levará para terminar. Compare os dois elementos.

0.2s
1s
.item {
    transition-duration: 0.2s;
}

.item:nth-child(2) {
    transition-duration: 1s;
}

Transition Timing Function

Controla como a velocidade da transição varia durante sua execução.

Transition Delay

Define quanto tempo o navegador aguardará antes de iniciar a transição.

Imediato
1 segundo
.item {
    transition: transform 0.5s;
}

.item:nth-child(2) {
    transition-delay: 1s;
}

Transition (Atalho)

.item {
    transition: background-color 0.5s ease 0.2s;
}

/* propriedade | duração | velocidade | atraso */

3. Transform

A propriedade transform permite modificar visualmente um elemento sem alterar a posição que ele ocupa no fluxo normal do documento.

Translate

Desloca o elemento horizontalmente e verticalmente.

Passe o mouse
.item:hover {
    transform: translate(20px, -15px);
}

Scale

Aumenta ou diminui o tamanho visual do elemento.

Passe o mouse
.item:hover {
    transform: scale(1.3);
}

Rotate

Rotaciona o elemento de acordo com o ângulo definido.

Passe o mouse
.item:hover {
    transform: rotate(45deg);
}

Skew

Inclina o elemento horizontalmente ou verticalmente.

Passe o mouse
.item:hover {
    transform: skew(20deg);
}

Transformações combinadas

É possível combinar diferentes transformações em uma única declaração.

Passe o mouse
.item:hover {
    transform: translateY(-10px) rotate(10deg) scale(1.1);
}

4. Keyframes

A regra @keyframes permite definir os diferentes estados de uma animação, determinando como o elemento deverá se comportar durante sua execução.

From e To

Representam o estado inicial e final de uma animação.

Movimento
@keyframes movimento {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }
}

.item {
    animation: movimento 2s;
}

Porcentagens

Permitem definir diferentes etapas da animação, incluindo estados intermediários.

Movimento
@keyframes movimento {
    0% {
        transform: translateX(0);
    }

    50% {
        transform: translateX(100px);
    }

    100% {
        transform: translateX(200px);
    }
}

.item {
    animation: movimento 3s infinite;
}

5. Animation Properties

As propriedades animation controlam a execução das animações criadas com @keyframes.

Animation Name e Duration

Definem o nome da animação e o tempo necessário para completar um ciclo.

Mudança de cor
.item {
    animation-name: mudar-cor;
    animation-duration: 3s;
}

@keyframes mudar-cor {
    0% {
        background-color: purple;
    }

    50% {
        background-color: orange;
    }

    100% {
        background-color: purple;
    }
}

Animation Direction

Define a direção em que a animação será executada.

  • normal: executa normalmente.
  • reverse: executa na direção inversa.
  • alternate: alterna entre normal e reverso.
  • alternate-reverse: começa no sentido reverso e alterna.
Normal
Reverse
Alternate
.item {
    animation: girar 2s infinite;
}

.item:nth-child(2) {
    animation-direction: reverse;
}

.item:nth-child(3) {
    animation-direction: alternate;
}

Animation Fill Mode

Controla como o elemento ficará antes e depois da execução da animação.

  • none: não mantém os estilos da animação.
  • forwards: mantém o estado final.
  • backwards: aplica o estado inicial durante o atraso.
  • both: combina forwards e backwards.
Aparecendo
.item {
    animation: aparecer 2s;
    animation-fill-mode: forwards;
}

Animation Play State

Permite controlar se uma animação está sendo executada ou pausada.

Passe o mouse para pausar
.item {
    animation: girar 3s infinite;
}

.item:hover {
    animation-play-state: paused;
}

Animation (Atalho)

.item {
    animation: movimento 2s ease 1s infinite alternate;
}

/* name | duration | timing-function |
   delay | iteration-count | direction */

6. Timing Functions

Controlam a velocidade da animação durante sua execução, determinando como ela acelera e desacelera.

Linear

Mantém uma velocidade constante durante todo o movimento.

Ease

Começa devagar, acelera e termina devagar.

Ease In

Começa devagar e acelera ao longo da animação.

Ease Out

Começa rápido e desacelera no final.

Ease In Out

Começa devagar, acelera no meio e desacelera no final.

Linear
Ease
Ease In
Ease Out
Ease In Out
.linear {
    animation-timing-function: linear;
}

.ease {
    animation-timing-function: ease;
}

.ease-in {
    animation-timing-function: ease-in;
}

.ease-out {
    animation-timing-function: ease-out;
}

.ease-in-out {
    animation-timing-function: ease-in-out;
}

Cubic Bezier

Permite criar curvas de velocidade personalizadas, controlando como a animação acelera e desacelera. 

.item {
    animation-timing-function: cubic-bezier(0.42, 0, 0.58, 1);
}

7. Delays e Iterations

Animation Delay

Define o tempo que a animação aguardará antes de começar.

0s
1s
2s
.item {
    animation: aparecer 2s;
}

.item:nth-child(2) {
    animation-delay: 1s;
}

.item:nth-child(3) {
    animation-delay: 2s;
}

Animation Iteration Count

Determina quantas vezes uma animação será executada.

1 vez
3 vezes
Infinito
.item {
    animation-iteration-count: 1;
}

.item:nth-child(2) {
    animation-iteration-count: 3;
}

.item:nth-child(3) {
    animation-iteration-count: infinite;
}

9. Microinterações

São pequenas respostas visuais que acontecem durante a interação do usuário com uma interface.

Feedback de botão

O botão muda de tamanho e cor quando o usuário passa o cursor ou clica nele.

Indicador de carregamento

Um elemento pode utilizar uma animação contínua para representar um processo que está acontecendo.

Carregando... 
@keyframes girar {
    from {
        transform: rotate(0deg);
    }

    to {
        transform: rotate(360deg);
    }
}

.item {
    animation: girar 1s linear infinite;
}

10. Animações responsivas

As animações podem ser adaptadas de acordo com o tamanho da tela, evitando movimentos exagerados ou inadequados em dispositivos menores.

No exemplo abaixo, o deslocamento do elemento diminui quando a largura da tela é menor que 600 pixels.

Movimento
@keyframes movimento {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }
}

@media (max-width: 600px) {
    @keyframes movimento {
        from {
            transform: translateX(0);
        }

        to {
            transform: translateX(80px);
        }
    }
}
O objetivo é adequar a intensidade e o comportamento das animações às diferentes condições de utilização.

11. Prefers Reduced Motion

Essa funcionalidade permite identificar se o usuário configurou seu dispositivo para reduzir movimentos e animações.

Quando essa preferência está ativada, é possível desabilitar animações não essenciais.

Movimento
.item {
    animation: movimento 3s infinite;
}

@media (prefers-reduced-motion: reduce) {
    .item {
        animation: none;
    }
}
Para testar esse comportamento, é necessário ativar a opção de redução de movimento nas configurações de acessibilidade do sistema operacional.

🎯 Conclusão

As animações CSS permitem criar interfaces mais dinâmicas, proporcionando feedback visual e melhorando a interação do usuário com os elementos da página.
