1. Introdução ao CSS

CSS (Cascading Style Sheets) é uma linguagem utilizada para definir a apresentação visual de documentos HTML.

Enquanto o HTML organiza o conteúdo, o CSS controla como esse conteúdo será apresentado ao usuário.

HTML

<h1>Olá, mundo!</h1>
<p>Minha primeira página.</p>

CSS

h1 {
    color: blue;
    font-size: 30px;
}

p {
    color: gray;
}

Resultado

Olá, mundo!

Minha primeira página.

Formas de adicionar CSS ao HTML

Existem três maneiras principais de aplicar CSS a um documento HTML.

Inline CSS

O estilo é aplicado diretamente na tag HTML, utilizando o atributo style. 

<p style="color: red;">
    Texto vermelho
</p>

Internal CSS

O CSS é escrito dentro da tag style, localizada geralmente no head do documento. 

<style>
    p {
        color: red;
    }
</style>

External CSS

Os estilos são escritos em um arquivo separado, conectado ao HTML através da tag link. 

<link rel="stylesheet" href="style.css">
Recomendação: utilizar CSS externo facilita a organização e manutenção dos projetos, principalmente quando existem várias páginas.

2. Seletores e Especificidade

Os seletores identificam quais elementos HTML receberão determinadas propriedades CSS.

Seletor Universal (*)

Seleciona todos os elementos da página.

* {
    margin: 0;
    padding: 0;
}

Seletor por Elemento

Seleciona elementos pelo nome da tag HTML.

Este é um parágrafo.

Este é um título.

p {
    color: blue;
}

h3 {
    color: blue;
}

Seletor por Classe (.)

Seleciona elementos que possuem determinada classe. Uma classe pode ser reutilizada em vários elementos.

Elemento com classe item

Outro elemento com a mesma classe

.item {
    background-color: blue;
    color: white;
}

Seletor por ID (#)

Seleciona um elemento através do seu identificador.

Elemento com ID exemplo-id

#exemplo-id {
    color: blue;
    font-weight: bold;
}

Especificidade

A especificidade determina qual regra CSS terá prioridade quando diferentes seletores aplicarem valores conflitantes.

De maneira geral, a prioridade é:

  1. Estilos inline.
  2. Seletores de ID.
  3. Seletores de classe, atributos e pseudo-classes.
  4. Seletores de elementos e pseudo-elementos.
p {
    color: blue;
}

.texto {
    color: green;
}

#principal {
    color: red;
}
Se um parágrafo possuir a classe texto e o ID principal, a cor vermelha será aplicada, pois o seletor de ID possui maior especificidade.

3. Cores e Backgrounds

O CSS permite controlar as cores dos textos, fundos e outros elementos de uma página.

Color

Define a cor do texto.

Texto vermelho.

Texto azul.

p {
    color: red;
}

Background Color

Define a cor de fundo de um elemento.

Fundo azul
.item {
    background-color: #1572B6;
}

Representação de cores

Existem diferentes formas de representar cores no CSS.

Tomato
HEX
RGB
RGBA
color: tomato;

color: #2B3B92;

color: rgb(30, 150, 100);

color: rgba(30, 150, 100, 0.5);

Background Image

Permite utilizar imagens como plano de fundo de um elemento.

Imagem de fundo

.container {
    background-image: url("imagem.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}
  • background-size: controla o tamanho da imagem.
  • background-position: define a posição da imagem.
  • background-repeat: controla sua repetição.

4. Fontes e Tipografia

As propriedades de tipografia controlam a aparência dos textos, incluindo família, tamanho, espessura e alinhamento.

Font Family

Este texto utiliza a fonte Georgia. 

p {
    font-family: Georgia, serif;
}

Font Size

Este texto possui 24 pixels. 

p {
    font-size: 24px;
}

Font Weight

Este texto possui uma espessura maior. 

p {
    font-weight: bold;
}

Font Style

Este texto está em itálico. 

p {
    font-style: italic;
}

Text Align

Texto centralizado. 

p {
    text-align: center;
}

Text Decoration

Texto sublinhado. 

p {
    text-decoration: underline;
}

Line Height

Este texto possui um espaçamento maior entre suas linhas.
É possível perceber que as linhas ficam mais afastadas,
facilitando a leitura de textos maiores. 

p {
    line-height: 2;
}

Letter Spacing

ESPAÇAMENTO 

p {
    letter-spacing: 5px;
}

5. Unidades de Medida

As unidades de medida definem dimensões, tamanhos e espaçamentos dos elementos.

Pixels (px)

Unidade absoluta de referência do CSS.

200px
.item {
    width: 200px;
}

Porcentagem (%)

Define um valor relativo às dimensões de referência estabelecidas pela propriedade.

50%
.item {
    width: 50%;
}

Em (em)

Unidade relativa ao tamanho da fonte do elemento de referência.

2em

.item {
    font-size: 2em;
}

Rem (rem)

Unidade relativa ao tamanho da fonte do elemento raiz, geralmente a tag html.

2rem

.item {
    font-size: 2rem;
}

Viewport Width (vw)

Representa uma porcentagem da largura da área visível do navegador.

50vw
.item {
    width: 50vw;
}

Viewport Height (vh)

Representa uma porcentagem da altura da área visível do navegador.

15vh
.item {
    height: 15vh;
}

6. Margin e Padding

Essas propriedades controlam os espaçamentos externos e internos dos elementos.

Margin

Define o espaçamento externo, separando um elemento dos outros elementos ao seu redor.

Elemento original
Margin de 30px
.item {
    margin: 30px;
}

Padding

Define o espaçamento interno entre o conteúdo e a borda do elemento.

Sem padding adicional
Padding de 30px
.item {
    padding: 30px;
}

Direções de espaçamento

Margin e Padding podem ser configurados individualmente para cada lado. 

margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;

padding-top: 10px;
padding-right: 20px;
padding-bottom: 30px;
padding-left: 40px;

7. Borders e Outlines

Permitem adicionar contornos aos elementos, controlando sua espessura, cor e aparência.

Border

Borda sólida
Borda tracejada
.item {
    border: 4px solid blue;
}

.item {
    border: 4px dashed blue;
}

Border Radius

Permite arredondar os cantos de um elemento.

Cantos arredondados
.item {
    border: 3px solid blue;
    border-radius: 20px;
}

Outline

Adiciona um contorno externo ao elemento, sem ocupar espaço no layout.

Outline
.item {
    border: 2px solid black;
    outline: 4px solid blue;
}

6. Display e Posicionamento

A propriedade display determina como um elemento participa do fluxo de layout da página.

Display Block

Ocupa uma linha inteira por padrão e permite controlar largura e altura.

Block 1
Block 2
.item {
    display: block;
}

Display Inline

Ocupa somente o espaço necessário ao conteúdo e não aceita width e height da mesma forma que elementos block.

Inline 1 Inline 2 Inline 3 
.item {
    display: inline;
}

Display Inline Block

Permite manter elementos na mesma linha, mas aceitando dimensões como width e height.

Item 1
Item 2
Item 3
.item {
    display: inline-block;
    width: 120px;
}

Display None

Oculta o elemento e remove seu espaço do fluxo de layout da página.

Elemento visível
Elemento oculto
Outro elemento visível
.item {
    display: none;
}

7. Pseudo-classes

São recursos utilizados para estilizar elementos em situações específicas.

Pseudo-classes

Permitem aplicar estilos quando um elemento apresenta determinada condição ou estado.

:hover

Aplica estilos quando o cursor está sobre um elemento.

Passe o mouse aqui
.item:hover {
    background-color: blue;
}

:active

Aplica estilos enquanto um elemento está sendo ativado, como durante um clique.

Clique e segure
.item:active {
    background-color: orange;
}

:focus

Aplica estilos quando um elemento recebe foco, como um campo de formulário. 

input:focus {
    background-color: lightblue;
    outline: 2px solid blue;
}

:first-child

Seleciona um elemento que seja o primeiro filho de seu elemento pai.

Primeiro parágrafo

Segundo parágrafo

Terceiro parágrafo

p:first-child {
    color: blue;
}

:last-child

Seleciona um elemento que seja o último filho de seu elemento pai.

Primeiro parágrafo

Segundo parágrafo

Último parágrafo

p:last-child {
    color: blue;
}
