## 📖 Sobre o projeto

Este repositório foi criado com o objetivo de documentar minha jornada de aprendizado em **CSS (Cascading Style Sheets)**, explorando desde os conceitos fundamentais até técnicas mais avançadas de estilização e desenvolvimento de interfaces.

O bootcamp está organizado em cinco níveis progressivos, cada um abordando conceitos específicos e exercícios práticos para consolidar o conhecimento adquirido.

A proposta é aprender na prática, desenvolver projetos e construir uma base sólida em desenvolvimento front-end.

---

## 📚 Conteúdos

### 🟢 Nível 01 — Básico

**Fundamentos e primeiros passos com CSS.**

- [x] Introdução ao CSS
- [x] Formas de adicionar CSS ao HTML
- [x] Seletores e especificidade
- [x] Cores e backgrounds
- [x] Fontes e tipografia
- [x] Unidades de medida (px, %, em, rem, vh, vw)
- [x] Margins e paddings
- [x] Borders e outlines
- [x] Display

---

### 🔵 Nível 02 — Flexbox

**Dominando layouts flexíveis.**

- [x] Introdução ao Flexbox
- [x] Display Flex
- [x] Flex Direction
- [x] Justify Content
- [x] Align Items e Align Content
- [x] Flex Wrap
- [x] Gap
- [x] Flex Grow, Shrink e Basis
- [x] Align Self
- [x] Order
- [x] Aplicações práticas do Flexbox

**Objetivo:** aprender a organizar elementos de maneira flexível, criando layouts adaptáveis e bem estruturados.

---

### 🟡 Nível 03 — Intermediário

**Explorando recursos e técnicas de estilização.**

- [ ] Position (Relative, Absolute, Fixed e Sticky)
- [ ] Z-Index e Stacking Context
- [ ] CSS Grid
- [ ] Variáveis CSS (Custom Properties)
- [ ] Pseudo-elementos avançados
- [ ] Seletores combinadores
- [ ] Especificidade e herança
- [ ] Overflow
- [ ] Gradientes
- [ ] Sombras e filtros
- [ ] Responsividade
- [ ] Media Queries

**Objetivo:** desenvolver interfaces mais complexas, organizadas e responsivas.

---

### 🟣 Nível 04 — Animações

**Dando vida às interfaces.**

- [ ] Introdução às animações CSS
- [ ] Transitions
- [ ] Transform
- [ ] Keyframes
- [ ] Animation Properties
- [ ] Timing Functions
- [ ] Delays e Iterations
- [ ] Animações de Hover
- [ ] Microinterações
- [ ] Animações responsivas

**Objetivo:** criar interfaces dinâmicas e interativas utilizando animações e transições.

### 🔴 Nível 05 — Avançado

**Indo além dos fundamentos.**

- [ ] CSS Nesting

- [ ] CSS Layers (@layer)

- [ ] Advanced Selectors (:has, :is e :where)
- [ ] Scroll Snap
- [ ] Scroll-driven Animations

- [ ] Organização e manutenção de código
- [ ] Performance e boas práticas
- [ ] Compatibilidade entre navegadores

**Objetivo:** dominar recursos modernos do CSS e desenvolver interfaces escaláveis, performáticas e profissionais.
